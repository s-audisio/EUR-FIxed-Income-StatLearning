# EUR-Fixed-Income-StatLearning

This project investigates the predictability of monthly EUR fixed-income returns using macroeconomic indicators.

## Methods

* Exploratory data analysis
* OLS regression
* Multicollinearity analysis
* Feature selection
* Decision Tree
* Random Forest
* Gradient Boosting

## Dataset

The analysis uses macroeconomic and financial indicators from the Macrosynergy Quantamental Indicators dataset.

## Main objective

The objective is to assess whether macroeconomic information can provide useful signals for predicting the direction of EUR fixed-income returns.
